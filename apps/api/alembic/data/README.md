# Reference data

`iran_geo_v3_2017.json` — provinces and cities of Iran, derived from
[ahmadazizi/iran-cities](https://github.com/ahmadazizi/iran-cities) release v3.0 (MIT licence, see
`LICENSE-iran-cities.txt`). Only entries of type "city" are kept (urban zones are dropped); names are
normalised to Persian ی/ک. The source data dates from 1396 (2017): cities created or renamed since then
are missing and can be added later with a new migration.
